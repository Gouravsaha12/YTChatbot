# YouTube Video Chatbot

A simple, conversational AI chatbot that lets you chat about any YouTube video using its transcript. Powered by **LangGraph**, **Chroma**, and **Groq**.

## Setup

1. **Install requirements:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Configure Environment Variables:**
   Create a `.env` file in the root folder and add your Groq API key:
   ```env
   GROQ_API_KEY=your_groq_api_key_here
   ```
   *(Optional)* Add a Hugging Face token to prevent rate limits when downloading embeddings:
   ```env
   HF_TOKEN=your_hf_token_here
   ```

## Usage

Run the main script from your project root:
```bash
python app/main.py
```

1. **Enter a YouTube video link** when prompted.
2. **Start chatting!** The bot will use the video's transcript to answer your questions.
3. **Type `exit` or `quit`** to end the conversation.

## Project Structure

```text
.
├── app/
│   ├── main.py               # The main entrypoint
│   ├── graph.py              # LangGraph orchestrator
│   ├── state.py              # Defines conversation state schema
│   ├── memory.py             # In-memory conversation history checkpointer
│   │
│   ├── nodes/
│   │   ├── ingest.py         # Fetches transcripts from YouTube
│   │   └── chat.py           # AI logic using Groq LLM
│   │
│   └── rag/
│       └── vectorstore.py    # Chunks text & stores embeddings in Chroma
│
├── data/                     # Auto-generated by app
│   ├── chroma_db/            # Chroma vector database storage
│   └── *.txt                 # Downloaded transcripts
│
├── .env                  # Your API keys
└── requirements.txt      # Python dependencies
```

## How It Works
- **Transcript Extraction**: Downloads the video transcript into the `data/` folder.
- **Embeddings & Vector Store**: Text is chunked and stored in a local Chroma database using Hugging Face embeddings.
- **LangGraph**: Maintains the conversational memory and guides the AI's thought process.
- **RAG Generation**: The Groq LLM fetches relevant context from the video to answer your questions accurately.
